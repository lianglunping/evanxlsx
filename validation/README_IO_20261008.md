## 验证中发现并保留的差异 / Observed limitations

1. **Empty strings versus missing Excel cells.** openxlsx2 1.29 and the tested readxl reader collapse an explicit empty string to NA on readback. Exact XLSX XML checks verify the writer still distinguishes an empty inline string from a value-less cell. The test checks documented reader normalization separately; it does not forgive arbitrary text/type mutation. CSV/TSV with the explicit sentinel preserve the fixture's empty string. Literal NA remains text. Rebuilding from readback data cannot recover the already-collapsed distinction.
2. **Quoted annotations in fread.** The first full annotation probe with data.table 1.18.6.1 retained doubled embedded quotes from the test TSV instead of recovering the original quotation mark. Its failure record is retained. The final documented fread example selects identifier/group/measurement columns; complete annotated data use readr followed by as.data.table(). No global guessed unescaping is applied. fwrite output is read back and checked separately.
3. **Polars future default warning.** scan_csv emitted an infer_schema_files default-change warning in Polars 1.16.0. Final examples set infer_schema_files=10 explicitly rather than suppressing warnings. The fixture is one file with declared column types.

Earlier runs 37743393889 and 37743941517 did not pass documentation acceptance. The second run improved diagnostics and ran every example to expose all failures. They are not combined with the final pass as if all attempts were successful. Their original macOS artifacts and failure logs are retained in the conversation evidence bundle.
