从清洗到 Excel：一条可运行的工作流

evanxlsx 0.3.1 · Chinese / English guide
已有Tidy动词负责通用操作；四个小函数负责明确规则；Excel输出继续使用同一个入口。

示例只使用确定性合成数据。版本本身不等于验收状态；实际运行、版本、哈希与限制以配套0.3.1验收报告为准。不安装字体，不修改原始研究数据，不默认填补测量值或删除异常值。

1. 先运行，再拆解 / Run the example

source(system.file("examples", "workflow.R", package = "evanxlsx"), encoding = "UTF-8")
result <- evanxlsx_workflow()
result$path

source只定义示例函数；实际调用后写入新临时目录。自定义目录需尚不存在，例如evanxlsx_workflow("workflow_demo")，不覆盖既有结果。示例函数不在NAMESPACE中新增导出，也不是要用户学习的新配置框架。
Source defines a demo, not an extra public package function. Running it uses a fresh output directory and refuses an existing one.

3. 清洗时先决定允许改变什么 / Cleaning contract

问题：注释有首尾空白、缺失批次与一条完全重复记录。思路：注释可规范化；测量不能无理由填0。批次可以在明确排序的处理组内向下补，不能跨组。选函数与参数：str_trim仅处理note；replace_na仅填注释；distinct去全行重复而不是任意重复ID；arrange确定fill顺序；.by隔离分组。

clean <- polars::pl$scan_parquet("raw.parquet") |>
  dplyr::mutate(note = stringr::str_trim(note)) |>
  tidyr::replace_na(list(note = "Unknown / 未记录")) |>
  dplyr::distinct() |>
  dplyr::arrange(treatment, Sample_ID) |>
  tidyr::fill(batch, .by = treatment, .direction = "down")

实际示例还显式把weight中的NaN转为null：pl_nan_to_null <- function(x) x$fill_nan(NULL)，并在mutate内使用。这个函数返回Polars表达式，不逐行回调R；原始RDS保持不变。文本“NA”不当成缺失值。
NaN normalization is explicit, not an implicit feature of every Tidy verb. Measurement values are not imputed.

4. 拆列和长宽转换 / Split and reshape

问题：Chr01:00001要拆开；测量列要转换成长表并能再转宽。参数：sep=":"是字面分隔符；into明确列名。pivot_longer只选择测量列；pivot_wider前先检查Sample_ID×trait唯一。重复键不自动求均值。

parts <- clean |>
  evanxlsx::separate_strict(locus, c("Chr", "Position"), ":", collect = TRUE)
long <- parts |>
  tidyr::pivot_longer(c(height, weight), names_to = "trait", values_to = "value")
wide <- long |>
  evanxlsx::assert_unique_keys(c(Sample_ID, trait), collect = TRUE) |>
  tidyr::pivot_wider(id_cols = c(Sample_ID, treatment),
                   names_from = trait, values_from = value)

检查：Position仍为字符，00001不变成1；每个样本×性状一行；长宽转换前后每个测量与缺失状态一致。

宽表的新列取决于trait中的取值，因此不能假设长转宽始终不执行查询。实际对象类型保存在stage_classes.csv。返回LazyFrame也不单独证明此前没有执行任何子查询；校验统计和动态列发现都可能提前执行。需要处理大数据时先限定目标列/记录和稳定输入。

5. 汇总和标记必须分开 / Summaries versus screening

summary <- clean |>
  evanxlsx::summarise_numeric(c(height, weight), .by = treatment)
flagged <- long |>
  evanxlsx::flag_iqr(value, .by = c(treatment, trait))
evanxlsx::write_xlsx(list(summary = summary, flagged = flagged),
                     "summary.xlsx", collect = TRUE)

示例没有先删掉异常值再汇总。缺失、零IQR、样本不足等未判定情况保持NA标记并给原因。主动filter(iqr_outlier==FALSE)也会排除未判定NA，不能当成中性的默认清洗。

6. 0.3.1数值修正 / Numeric correction

新增边界复测在0.3.0中复现：1:4×10^-200的SD为0、1:4×10^200的SD为Inf，以及重复10^308的均值为Inf。0.3.1计算先以2的整数幂缩放均值/SD的中间量，最后恢复原单位。输入、计数、缺失规则、四分位数与公开参数不变。

缩放指数被限制在Float64正常幂范围−1022至1023，这是浮点表示范围而非删除数据的阈值。它不是任意精度计算，不保证所有极端分布的全部统计量都可表示，也不恢复上游已经损失的精度。真实超出Float64范围的结果仍可能非有限。

测试用“结果÷尺度”比较无量纲值，避免0与极小真值因宽松绝对误差被误判相等；原有普通数值与分组测试仍需通过。

7. 安装与日常入口 / Installation

install.packages("remotes")
remotes::install_github("lianglunping/evanxlsx",
                        dependencies = NA, upgrade = "always")
# 可选工作流依赖 / Optional workflow dependencies
install.packages(c("dplyr", "tidyr", "stringr", "rlang", "tidyselect"))
Sys.setenv(NOT_CRAN = "true")
install.packages(c("polars", "tidypolars"),
                 repos = c("https://community.r-multiverse.org", "https://cloud.r-project.org"))

私有仓库需本机读取凭据。always允许更新相关依赖，不等于锁定研究环境；固定依赖需在项目层处理。仅Excel输出不要求安装完整数据模块。示例要求缺少依赖时明确停止，不在执行中安装软件。

English summary

The installed example connects Parquet input, explicit annotation cleaning, ordered within-group filling, exact-duplicate removal, strict splitting, long/wide reshaping, grouped summaries, non-destructive IQR flags and Excel output. It preserves raw fixtures and records actual stage classes and query plans. It does not provide blanket Tidy compatibility or assume that dynamic pivots never execute early. The numeric patch rescales mean/SD intermediates by powers of two; public signatures and missing-data policies are unchanged. Test evidence and residual Float64/viewer limitations must be read separately from this guide.
