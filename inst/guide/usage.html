中文使用指南 / English usage guide
一个导出函数；数据处理与Excel排版分离。One exporter; data transformation stays upstream.

实际测试状态以本版 validation/STATUS_0.2.1.md 及日志为准。版本说明不等于测试结果。Consult version-specific validation records, not this guide, for actual acceptance.

安装 / Installation

install.packages("remotes")
remotes::install_github("lianglunping/evanxlsx",
                        dependencies = NA, upgrade = "always")
# 本地 R 构建包 / Local R-built archive
remotes::install_local(file.choose(), dependencies = NA, upgrade = "always")

私有仓库需要本机读取凭据。NA只解析必要依赖，不安装全部可选后端；always可能更新相关依赖。研究项目需固定环境时，先在项目包库中管理依赖版本，不能把固定本包提交等同于固定依赖。离线安装需要事先准备R与依赖。导出时不安装软件。
Private access needs a local credential. NA resolves required dependencies; always permits dependency updates. A pinned package commit does not pin dependencies. Offline use needs pre-provisioned R/dependencies. Export never installs software.

日常导出 / Everyday export

evanxlsx::write_xlsx(list(var = df, id83 = df1), "WES.xlsx")
evanxlsx::write_xlsx(df, "Arial.xlsx",
                     font = "Arial", font_size = 12, align = "left")
参数默认 / Default用途 / Meaning
font / font_sizeTimes New Roman / 11全表统一；可设Arial、SimSun/宋体。Uniform font.
align / header_aligncenter / center分别控制正文与表头；center/left/right/justify。
valign / wrapcenter / TRUE垂直对齐与换行。Vertical alignment and wrapping.
freeze / freeze_first_colTRUE / FALSE首行/首列冻结。Freeze row/column.
widths / max_widthauto / 40固定widths=16时完全忽略max_width。Fixed widths ignore max_width.
three_line / grid_linesTRUE / FALSE三线表/网格线。Borders/grid.
filter / overwriteFALSE / FALSE筛选与整工作簿替换。Filter/whole-workbook replacement.
collect / max_rowsFALSE / 1048575后端执行许可与数据行数预算。Query permission/returned rows.

数据规则 / Data rules

NA和NaN写为空白无值单元格，文本“NA”不变；字符编号保持文本。自定义行名不导出并给警告。重要ID请明确放入列，例如：
Missing values become value-less cells; literal NA is retained. Custom row names are omitted with a warning. Make important IDs explicit:

df <- tibble::rownames_to_column(df, var = "Gene_ID")

0.2.1临时固定openxlsx2的numFmt、dateFormat、datetimeFormat、string_nums、borderColor为普通数值、yyyy-mm-dd日期、yyyy-mm-dd hh:mm:ss日期时间、保留字符、黑色边框。退出时恢复这些选项；不是清空全部options。压缩和页面等其他设置不在此约定范围。
Relevant formatting defaults are locally isolated and restored, not all global options. Other options such as compression/page setup remain outside this contract.

duckplyr与Polars / Optional backends

install.packages("duckplyr")
Sys.setenv(NOT_CRAN = "true")
install.packages("polars", repos = c("https://community.r-multiverse.org",
                                    "https://cloud.r-project.org"))

evanxlsx::write_xlsx(list(duck = duck_result, polars = polars_query),
                     "backend.xlsx", collect = TRUE, max_rows = 100000)

所有duckplyr对象及Polars LazyFrame需collect=TRUE；DataFrame不需要。限制针对最终结果，最多取上限+1行检测，超限报错而非截断。查询内部排序/连接资源不受行数限制。核心R≥4.1.3与后端要求分开；Polars≥1.16.0且<2.0.0。逐sheet转换不是流式XLSX。
Lazy execution is explicit and bounded by returned rows, not engine resource use. Core and optional-backend compatibility differ; this is not streaming XLSX.

Polars时间列按已知位置选择，不解释列名中的*或正则字符。长整数先保留准确字符再决定数值转换；Decimal保留文本。Time明确保留九位小数秒；Datetime保留文本，不声称原生Excel可存储全部纳秒/时区语义。嵌套、二进制、Duration需上游显式转换。已损失的精度不能恢复。
Temporal columns are selected by position. Exact text protects wide integers, Decimal and time precision. Unsupported complex types require upstream conversion.

文件保护 / File protection

默认不覆盖。明确overwrite=TRUE时先保留.bak；新工作簿完成后才尝试最终复制。复制失败时尽力恢复旧目标，或删除新残缺目标；完整新工作簿及有效备份保留，位置在错误信息中。恢复也可能失败，请检查提示。不是并发锁或断电安全事务；不要多进程写同一路径。
Explicit overwrite backs up first. Failed publication attempts recovery and retains the complete new workbook. Recovery may fail; follow the error paths. No transactional/crash-safety/concurrent-writer guarantee.
