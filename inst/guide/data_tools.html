可选数据工具 / Optional data tools

版本0.3.0。四个规则明确的小函数；保留Tidy选列语法、由Polars执行，不重写通用Tidy动词。实际发布验收状态另见validation/STATUS_0.3.0.md。

四个函数均返回Polars LazyFrame。统计和标记不主动取回完整数据；严格拆列、唯一键检查需要执行验证。NA/NaN统一处理是本模块明确约定，不意味着所有tidypolars操作都自动采用同样规则。

1. 多列分组汇总 / Grouped numeric summaries

问题：不同处理的株高、粒重需要相同统计口径，且必须知道每组有多少有效观测。
选函数：summarise_numeric一次生成数量和统计量，不需要复制多段mean/sd。选参数：.cols选测量列；.by选分组列；na_rm默认TRUE忽略NA/NaN，FALSE使有缺失的组统计值为缺失。它不是填补缺失值。

library(evanxlsx)
summary <- df |>
  summarise_numeric(c(height, weight), .by = treatment)
write_xlsx(summary, "summary.xlsx", collect = TRUE)
# 查看小型结果 / Inspect a small result
as.data.frame(summary$collect())
后缀 / Suffix定义 / Meaning
__n_total全部观测数。
__n_valid有限数值的数量，不包含Inf。
__n_missingNA/null与NaN数量。
__n_infinite正负无穷数量。
__mean / __median / __sd均值、中位数、样本标准差，SD使用n−1。
__q1 / __q3 / __iqrlinear分位数，对应有限数据的R type=7；IQR=Q3−Q1。

检查：n_total=n_valid+n_missing+n_infinite。若某组某列有Inf，其描述统计全部为缺失并记录n_infinite，不悄悄排除Inf后给出普通结果。全缺失时统计值为缺失，单个有效值时SD为缺失。空的未分组输入返回一行零计数；空的分组输入返回零行。

测量列支持普通32位及以下整数、UInt32、Float32/64；Int64/UInt64/Decimal要求上游显式转换，避免无声损失精度。字符编号不自动转数值。分组键与测量列不能重叠。列选择支持裸列名、c()、all_of()、starts_with()；暂不支持where()或边选边改名。

2. IQR标记而不是自动删除 / Flag, do not delete

问题：想查看哪些观测超出IQR范围，但不能直接丢掉原始数据。参数：k=1.5是标记规则倍数；min_n=4是可调整的工作约定，不是普遍的统计样本量标准。.by防止混合不同处理的分布。

flagged <- df |> flag_iqr(height, .by = treatment, k = 1.5, min_n = 4)
# 保留全部行，查看标记 / All rows remain
as.data.frame(flagged$collect())

新增iqr_n_valid、iqr_q1、iqr_q3、iqr_lower、iqr_upper、iqr_outlier、iqr_reason。上下界Q1−k×IQR与Q3+k×IQR，严格小于/大于才标TRUE，等于边界不标记。缺失行、组内Inf、样本不足、IQR=0时标记为NA，不假装FALSE；原因分别为missing、infinite_in_group、insufficient_n、zero_iqr。普通可判定行原因为tested。原列和原始行数不变，新增列撞名直接报错。

以下是你主动决定的后续分析，不是默认行为；未判定的NA标记也会被此筛选排除，须先审查原因。
The following is explicit exclusion, not automatic data cleaning; unclassified flags are also excluded.

library(dplyr)
library(tidypolars)
options(tidypolars_unknown_args = "error", tidypolars_fallback_to_r = FALSE)
kept_summary <- flagged |>
  filter(iqr_outlier == FALSE) |>
  summarise_numeric(height, .by = treatment)

3. 严格拆列 / Literal strict splitting

问题：Chr01:00123需要拆成染色体和位置，但00123不能变成123；字段多/少不能悄悄删掉。选参数：sep仅按字面处理，.、|、::都不是正则；into明确每个字段名称；默认保留源列remove=FALSE。

parts <- df |>
  separate_strict(locus, into = c("Chr", "Position"), sep = ":")
# LazyFrame需明确允许验证执行 / Permission for lazy validation
parts <- polars_query |>
  separate_strict(locus, c("Chr", "Position"), ":", collect = TRUE)

每条非缺失记录必须正好包含指定数量字段，否则报错。NA源字符串产生NA字段；连续分隔符产生空字符串，不自动当NA。字段保留字符类型、空白和前导零；不进行CSV引号/转义解析。新列不允许覆盖已有列；输出字段追加到末尾。

4. 长转宽前查键 / Keys before pivoting

问题：Sample_ID×trait有重复，直接转宽可能需要聚合，但不能替你决定平均。选函数：assert_unique_keys检查组合唯一且默认不缺失；若重复/缺失直接报错。allow_missing=TRUE仅放宽缺失约束，不放宽唯一约束。

library(tidyr)
library(tidypolars)
wide <- long_table |>
  assert_unique_keys(c(Sample_ID, trait)) |>
  pivot_wider(id_cols = Sample_ID, names_from = trait, values_from = value)

LazyFrame校验加collect=TRUE。校验执行一次分组统计，随后返回原查询供继续管道使用；转宽或导出可能再次读取数据源，故需使用稳定输入。这不是动态文件/数据库事务快照。仅取小型校验统计回R，不等于源扫描或引擎内存没有成本。

5. 已有动词继续复用 / Reuse existing verbs

long <- polars_query |>
  pivot_longer(c(height, weight), names_to = "trait", values_to = "value")
filled <- polars_query |>
  replace_na(list(count = 0, note = "Unknown"))
ordered <- polars_query |>
  arrange(Sample_ID, time) |>
  fill(label, .by = Sample_ID, .direction = "down")

0是有效数值，只在确实应填0时使用。向下填充必须明确分组与顺序。tidypolars 0.19.0已知调用边界仍存在：原生IQR、mean(trim)、pivot_wider(values_fn)、separate_wider_delim等不能据此声称全部支持；不要把不支持的参数静默忽略。

English contract summary

All four helpers return native Polars LazyFrames. They use Tidy selection but do not implement an arbitrary R-expression compiler. Summary and flag helpers build native Polars expressions only; scalar validation aggregates execute for strict split/key checks, requiring collect=TRUE for lazy inputs. No R row-wise callbacks, hidden fallback, input modification, guessed imputation or automatic outlier deletion. Numerical policies, unclassified reasons, name collisions and finite measurement type restrictions are explicit. The existing Excel exporter stays independent.
