One Excel writer for ordinary R data frames, duckplyr and R Polars.

1. 安装与依赖 / Installation

install.packages("remotes")
remotes::install_github(
  "lianglunping/evanxlsx", ref = "feature/0.2.0-backends",
  dependencies = NA, upgrade = "always"
)
# 本地 tar.gz，并解析必要依赖 / Local archive plus dependency resolution
remotes::install_local(file.choose(), dependencies = NA, upgrade = "always")

私有仓库需要在本机配置读取凭据，不要把凭据发到会话或写入代码仓库。验收后可将 ref 换为报告中的完整提交 SHA 固定版本。
Private access needs a local read credential. Do not share or commit credentials. Pin ref to the tested commit SHA in the report for reproducibility.

dependencies=NA 只选择必要的 Depends/Imports/LinkingTo，不安装全部可选后端或测试包。upgrade="always" 允许更新解析到的必要依赖，可能更新已经满足最低版本的依赖；不是更新整个 R 包库。实测 upgrade="never" 不会修复已经安装但过旧的依赖，因此不能作为无条件的一键安装推荐。受控环境中先确认依赖版本，再使用 never 固定现有依赖。
NA selects required dependency fields. Always allows resolved dependencies to update, including those already satisfying minima, but is not a full-library update. Never failed the installed-but-outdated dependency fixture; use it only after confirming dependency versions.

基础 R 的 install.packages(..., repos=NULL) 不会下载缺失依赖。安装器负责依赖；write_xlsx() 不安装或更新软件。不联网时必须提前准备 R、依赖和系统组件，这不是完整离线环境。升级已加载的包后应重启 R。
Base install.packages with repos=NULL does not download dependencies. Export never installs software. Offline use requires pre-provisioned R and dependencies. Restart R after upgrading loaded packages.

evanxlsx::write_xlsx(list(var = df, id83 = df1), "WES.xlsx")
evanxlsx::write_xlsx(df, "Arial.xlsx", font = "Arial",
                     font_size = 12, align = "left", header_align = "center")

font / font_sizeTimes New Roman / 11 pt；全表统一，可改 Arial 或 SimSun/宋体。Uniform font throughout.
align / header_aligncenter / center；分别控制数据与表头，支持 center/left/right/justify。Independent body/header alignment.
valign / wrapcenter / TRUE；垂直对齐、换行。Vertical alignment and wrapping.

widths / max_widthauto / 40；也可固定 widths=16。Automatic or fixed widths.
three_line / grid_linesTRUE / FALSE；三线表，隐藏网格线。Three-line borders, hidden grid.

NA/NaN/后端空值变为空白无值单元格，文本“NA”保留。overwrite=TRUE 先备份后替换整个工作簿，不是追加 sheet。不安装或嵌入字体；缺字体时显示可能替代。换行不保证 Excel 自动调整行高。
Missing values become value-less cells; literal NA remains text. Explicit overwrite preserves a backup and replaces the whole workbook. Fonts are not installed or embedded. Wrapping is not guaranteed row autofit.

3. 可选后端 / Optional backends

install.packages("duckplyr")
Sys.setenv(NOT_CRAN = "true")  # Polars 安装会话 / Installation session
install.packages("polars", repos = "https://community.r-multiverse.org")

q_duck <- duckplyr::as_duckdb_tibble(df, prudence = "stingy")
p_df <- polars::as_polars_df(df1)
p_query <- p_df$lazy()
evanxlsx::write_xlsx(
  list(duck = q_duck, polars = p_df, query = p_query),
  "mixed.xlsx", collect = TRUE, max_rows = 100000
)

普通导出只直接依赖 openxlsx2；没有强制安装 Python、Arrow 或所有后端。所有 duckplyr 对象及 Polars LazyFrame 要求 collect=TRUE；已计算的 Polars DataFrame 不要求。也可上游显式 collect。核心 R≥4.1.3，可选 Polars 当前要求 R≥4.3；适配 duckplyr≥1.2.1、Polars≥1.16.0且<2.0.0，2.x 待重新验证。
Ordinary export directly depends only on openxlsx2. All duckplyr frames and Polars LazyFrames need collect=TRUE; eager Polars frames do not. Core and optional backend R requirements differ. Polars 2.x is rejected pending revalidation.

4. 规模与类型保护 / Size and types

max_rows 是每个 sheet 的数据行数预算，不含表头，0 表示只允许空表。默认1048575是 Excel 硬限制，不是安全内存值。延迟查询对最终结果取至多 max_rows+1 行，执行一次，不先跑完整 count；超限报错，不截断。它不限制连接、排序、扫描的内部内存或运行时间。逐 sheet 转换不等于流式 XLSX。要求稳定顺序时请先排序。
The row cap bounds returned rows, not query-engine resources. Lazy collection uses one bounded final query, never a separate full count. Over-limit exports fail without truncation. Per-sheet conversion is not streaming XLSX. Sort upstream for stable order.

类型 / Type规则 / Policy
字符编号 / Character IDs准确文本，保留前导零。Exact text with leading zeros.
普通数字 / Ordinary numbers保持数值。Remain numeric.
Polars Int64/UInt64/UInt32先准确转字符再检查；全列非缺失整数≤15位才写为数值，否则整列文本。Exact-string range checks precede conversion.
Polars Decimal保持精确文本，不先转 double。Exact text.
Polars Datetime/Time在 Polars 内先转文本以避免 POSIXct 转换损失；不等于原生 Excel 日期时间或完整时区语义往返。Text before R temporal conversion.
Date保持日期。Remain dates.
List/Struct/Array/Binary/Duration报错，要求主动展开或转换。Explicit conversion required.
普通 R/duckplyr integer64请上游准确转为字符。Convert explicitly upstream.

上游已经丢失的精度无法恢复。先检查输出条件和参数，再检查元数据，最后执行查询；不改 duckplyr prudence。工作簿不是并发写入锁，勿多个进程同时写同一个路径。
Already-lost precision is unrecoverable. Output checks precede input evaluation; prudence is not changed. Do not concurrently write the same path.
